## Product Contract

Editors need an admin authoring structure that matches the structured tour
domain instead of forcing them to infer product meaning from generic fields.

## Acceptance Criteria

- base tours expose grouped authoring fields for decision data, route, reviews,
  itinerary, services, FAQ, and builder settings
- departures expose grouped commerce signals
- variants expose grouped override tabs

- product docs added for editorial operations and import mapping

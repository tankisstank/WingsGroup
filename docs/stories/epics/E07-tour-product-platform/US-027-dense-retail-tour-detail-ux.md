# US-027 Dense Retail Tour Detail UX

## Status

implemented

## Lane

high-risk

## Product Contract

`WingsGo` tour detail pages must behave like dense retail decision pages rather
than generic content pages.

## Acceptance Criteria

- hero becomes a decision header
- review snapshot and route visual are visible
- itinerary is day-by-day and gallery-aware
- services and departures read like commerce modules
- sticky CTA stays builder-ready

## Evidence

- governed tour sections implemented in the tour renderer
- detail page uses resolved structured data instead of wrapper-page blocks
- validation checks passed

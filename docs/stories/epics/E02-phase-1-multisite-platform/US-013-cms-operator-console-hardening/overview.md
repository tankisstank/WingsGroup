# Overview

## Current Behavior

US-012 added the CMS management console baseline and quick page wizard. The remaining CMS audit backlog still exposes too much Payload-native terminology and plugin UI to non-technical operators.

## Target Behavior

CMS users land on an operator-focused console with Vietnamese task language, role-aware shortcuts, clear lead/import/export guidance, and reduced technical navigation for editor and site-manager roles.
The quick page wizard also provides advanced template scaffolds for homepage,
service, destination, tour, lead capture, and contact scenarios.

## Affected Users

- `editor`
- `site-manager`
- `super-admin`

## Affected Product Docs

- `source/strategy/18 Áp dụng Payload vào dự án WingsTravel.md`
- `source/strategy/19 Kiến trúc đề xuất nội bộ WingsTravel Payload.md`

## Non-Goals

- Replace Payload admin.
- Build a CRM workflow.
- Replace the official import/export plugin.
- Add database migrations.

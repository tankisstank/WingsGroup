# Site Manager Guide

## Responsibilities

- Manage content for assigned sites
- Review and publish content when in scope
- Maintain site-specific shared settings if permitted

## Core Tasks

### Review Assigned Sites

1. Open `/admin`.
2. Open `Console vận hành`.
3. Use the assigned-site chips or `Cấu hình site > Cấu hình site` to confirm
   the sites visible to your account.

### Manage Content

1. Create pages with `Tạo trang nhanh` or edit pages/posts from `Nội dung`.
2. Select the correct site in the sidebar.
3. Edit the correct locale.
4. Save draft and preview.
5. Publish after checklist review.

### Manage Shared Site Content

1. Open `Cấu hình site > Cấu hình site`.
2. Update navigation items, footer items, contact details, and SEO defaults.
3. Confirm the selected site before saving.
4. Check the public site after publish or settings updates.

### Leads And Data Exchange

1. Open `Lead > Lead gửi về` or the console `Lead mới` shortcut.
2. Review only submissions for assigned sites.
3. Use `Dữ liệu > Xuất dữ liệu` for approved content and lead export tasks.
4. Use `Dữ liệu > Nhập dữ liệu` only for prepared content files; imported
   pages and posts should be reviewed as drafts before publish.

## Checks Before Publish

- Correct site selected
- Correct locale selected
- Copy approved
- Images approved
- Links verified
- Lead capture form is connected when the page includes an inquiry section

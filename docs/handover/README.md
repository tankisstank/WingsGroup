## Update Rule

Before final delivery:

1. Replace placeholders with project-specific facts.
2. Remove sections that truly do not apply.
3. Mark unknown or deferred items explicitly instead of leaving them implied.
4. Confirm that operational steps match the deployed environment and live role
   permissions.

internal implementation team.

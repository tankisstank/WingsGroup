# Editor Guide

## Responsibilities

- Create and edit content inside assigned scope
- Prepare content and images for review
- Follow publishing workflow defined by the project

## Core Tasks

### Create Content

1. Open `/admin/console`.
2. Use `Tạo trang nhanh` for a guided page draft or start a new post from `Nội dung`.
3. Select the correct site
4. Select the correct locale
5. Add copy and images
6. Save as draft

### Update Content

1. Find existing content from `Console vận hành` or `Nội dung`
2. Edit fields and sections
3. Save draft
4. Preview the draft
5. Send the page or post to a site manager or super admin for publishing

## Publishing Limit

Editors cannot publish directly. The CMS allows editors to prepare drafts in
their assigned sites, while `site-manager` and `super-admin` accounts handle the
final publish action.

Editors do not use import/export in this phase. Lead records are generated by
website forms and should not be created manually in the CMS.

## Editorial Checklist

- Title is complete
- Body copy is complete
- Images are uploaded and placed correctly
- SEO or sharing fields are reviewed when required
- Wrong-site and wrong-locale errors are checked
- The draft has been sent to the correct publisher

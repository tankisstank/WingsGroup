# Editor Guide

## Responsibilities

- Create and edit content inside assigned scope
- Prepare content and images for review
- Follow publishing workflow defined by the project

## Core Tasks

### Create Content

1. Start a new page or post
2. Select the correct site
3. Select the correct locale
4. Add copy and images

### Update Content

1. Find existing content
2. Edit fields and sections
3. Save draft
4. Submit for review or publish if allowed

## Editorial Checklist

- Title is complete
- Body copy is complete
- Images are uploaded and placed correctly
- SEO or sharing fields are reviewed when required
- Wrong-site and wrong-locale errors are checked

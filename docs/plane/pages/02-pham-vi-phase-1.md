# Phạm vi giai đoạn 1

## Trong phạm vi

- dựng nền CMS đa site cho WingsGroup
- sẵn sàng cho WingsTravel và các site con
- quản trị trang nội dung, landing page, bài viết và media
- đa ngôn ngữ tiếng Việt và tiếng Anh
- cấu hình theo từng site
- vai trò và quyền truy cập theo phạm vi site
- SEO nền tảng, preview và quy trình publish

## Ngoài phạm vi mặc định

- CRM nhiều bước
- hệ thống booking
- payment
- workflow automation chuyên sâu
- chatbot AI
- dashboard analytics nâng cao

## Định hướng hạ tầng

- local: SQLite
- staging: PostgreSQL
- production: PostgreSQL và Redis

## Cách đọc tiến độ trên Plane

- project `Nền tảng lõi WingsGroup` theo dõi phần nền tảng dùng chung
- mỗi project site con theo dõi công việc riêng theo site
- work item cha là story delivery
- child task mô tả tiêu chí chấp nhận chính và phần việc liên quan

# Quy trình cập nhật nội dung

## Trường hợp áp dụng

- tạo page mới
- cập nhật nội dung page hiện có
- tạo landing page cho campaign
- cập nhật bài viết, media hoặc nội dung đa ngôn ngữ

## Luồng thực hiện

1. chọn đúng site
2. mở đúng page hoặc tạo bản mới
3. cập nhật nội dung theo locale
4. kiểm tra trường SEO và media
5. preview trên giao diện public
6. gửi review nếu cần
7. publish khi được phê duyệt

## Kiểm tra tối thiểu

- đúng site
- đúng locale
- tiêu đề và section chính đầy đủ
- CTA và contact link chính xác
- media hiển thị đúng
